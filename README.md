## ✨ Features

* **🎨 Modern GitHub Dark Theme:** Matches standard dark mode aesthetics with sleek project cards and border accents.
* **📱 Fully Responsive:** Responsive CSS grid layout that adapts seamlessly to desktop, tablet, and mobile screens.
* **⚡ Zero Dependencies:** Pure HTML5 and vanilla CSS—no external frameworks, heavy JavaScript libraries, or build steps required.
* **🚀 GitHub Pages Ready:** Ready to deploy in seconds via GitHub Pages, Vercel, Netlify, or Render.

## 🛠️ How to Use & Customize

### 1. Fork & Clone the Repository
Click the **Fork** button at the top right of this page, then clone your fork:

```bash
git clone [https://github.com/YOUR-USERNAME/developer-portfolio.git](https://github.com/YOUR-USERNAME/developer-portfolio.git)
cd developer-portfolio
```

### 2. Customize index.html
Open index.html in your favorite code editor and edit the following sections:

* Header: Update your name and title inside the <header> block:
```
<h1>Your Name</h1>
<p>Your Title / Specialty</p>
```
* Project Cards: Duplicate or edit the .card blocks inside <div class="projects-grid"> with your own project title, description, tech tags, and links:
```
<div class="card">
  <div>
    <h3>Project Title</h3>
    <p>Short project description...</p>
    <div class="tags">
      <span class="tag">HTML</span>
      <span class="tag">CSS</span>
    </div>
  </div>
  <a href="[https://github.com/YOUR-USERNAME/YOUR-REPO](https://github.com/YOUR-USERNAME/YOUR-REPO)" target="_blank" class="card-link">View Repository &rarr;</a>
</div>
```
* Footer Links: Change the social/GitHub link at the bottom of the page.

---

## 🌐 Deployment (GitHub Pages)

1. Go to your repository Settings on GitHub.

2. Select Pages from the left sidebar.

3. Under Build and deployment > Branch, select main and / (root), then click Save.

4. Your site will be live at https://YOUR-USERNAME.github.io/developer-portfolio/ in a few moments.
