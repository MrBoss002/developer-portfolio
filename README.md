## ✨ Features

* **🎨 Modern GitHub Dark Theme:** Matches standard dark mode aesthetics with sleek project cards and border accents.
* **📱 Fully Responsive:** Responsive CSS grid layout that adapts seamlessly to desktop, tablet, and mobile screens.
* **⚡ Zero Dependencies:** Pure HTML5 and vanilla CSS—no external frameworks, heavy JavaScript libraries, or build steps required.
* **🚀 GitHub Pages Ready:** Ready to deploy in seconds via GitHub Pages, Vercel, Netlify, or Render.
